# Conceptual Model of the Causal Transition Condition (CTC)

## 1. The Core Idea

Most adaptive systems change.

The important distinction is whether they can change the mechanism responsible for changing.

CTC separates two regimes:

\[
\text{adaptation}
\]

from:

\[
\text{recursive adaptation}
\]

A system can become better while remaining inside a fixed possibility space.

A recursive adaptive system can change the boundaries of that possibility space.

---

# 2. Adaptation vs Recursive Adaptation

## Ordinary Adaptation

A standard adaptive loop:

\[
Reality \rightarrow System \rightarrow Better State
\]

The environment changes:

- actions
- beliefs
- parameters
- outputs

The system improves according to an existing adaptive mechanism.

Example:

\[
X_t \rightarrow X_{t+1}
\]

The system changes.

The mechanism of change remains fixed.

---

## Recursive Adaptation

A recursive adaptive loop:

\[
Reality
\rightarrow
\text{Adaptive Mechanism}
\rightarrow
\text{New Adaptive Mechanism}
\]

The environment can modify:

- strategies
- search processes
- learning rules
- architectures
- objectives

The system does not only improve.

It improves the process by which improvement occurs.

---

# 3. The Possibility Space

Every adaptive system operates inside some space of reachable futures.

Represent this as:

\[
\mathcal{G}
\]

where:

\[
\mathcal{G}_t =
\text{space of reachable adaptive mechanisms at time } t
\]

A fixed system:

\[
\Delta\mathcal{G}=0
\]

can search within its existing possibilities.

A recursive system:

\[
\Delta\mathcal{G}\neq0
\]

can expand, contract, or reshape the space itself.

---

# 4. The Role of Reality

Reality is not just a source of information.

It is a source of constraint.

Define:

\[
\Omega_t
\]

as the constraint information produced by interaction with reality.

Examples:

- failed predictions
- unexpected outcomes
- environmental pressure
- resource limitations
- new observations

The CTC condition is:

\[
\boxed{
\Omega_t \rightarrow \Delta\mathcal{G}_{t+1}
}
\]

Reality changes the future space of possible adaptations.

---

# 5. The Closed System

A closed adaptive system:

   Reality

      |
      v

 Existing Mechanism

      |
      v

 Better Performance

 
The system receives feedback.

However:

\[
\Omega_t \not\rightarrow \Delta\mathcal{G}_{t+1}
\]

The mechanism itself remains protected.

---

# 6. The Open System

An open adaptive lineage:

         Reality

            |
            v

      Constraint Information
            |
            v

    Adaptive Mechanism Space

            |
            v

      New Adaptive Processes

            |
            v

          Reality


The loop becomes:

\[
R \rightarrow \Omega \rightarrow C \rightarrow A \rightarrow R'
\]

where:

- \(R\) = reality
- \(\Omega\) = extracted constraints
- \(C\) = correction
- \(A\) = adaptation
- \(R'\) = changed interaction with reality

---

# 7. Why Self-Modification Is Not Enough

A system can rewrite itself without being open-ended.

Example:

\[
C_{rev,t+1}=f(C_{rev,t})
\]

The system modifies its own rules.

However, the source of modification is internal.

It follows a trajectory:

\[
C_{rev,0}
\rightarrow
C_{rev,1}
\rightarrow
C_{rev,2}
\]

The system moves.

But reality cannot alter the direction of movement.

---

# 8. The Causal Permeability Requirement

CTC depends on a deeper property:

\[
E^*\rightsquigarrow C_{rev}
\]

Meaning:

Reality retains access to the mechanism that determines future change.

This is the Causal Permeability Principle.

CTC describes what happens after that access exists:

\[
E^*\rightsquigarrow C_{rev}
\rightarrow
\Delta\mathcal{G}
\]

---

# 9. Trajectory vs Lineage

## Trajectory

A trajectory is a system evolving through a predefined adaptive landscape.

\[
\text{Change inside possibility space}
\]

---

## Lineage

A lineage is a system where reality can reshape the adaptive landscape itself.

\[
\text{Change of possibility space}
\]

---

# 10. Final Compression

The distinction:

\[
\boxed{
\text{A system that adapts changes itself.}
}
\]

\[
\boxed{
\text{A recursive system allows reality to change what adaptation means.}
}
\]

The Causal Transition Condition is the boundary between these two regimes:

\[
\boxed{
\Omega_t \rightarrow \Delta\mathcal{G}_{t+1}
}
\]
