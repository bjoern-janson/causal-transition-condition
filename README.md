# Causal Transition Condition (CTC)

## Detecting when adaptation becomes recursive

## Abstract

Adaptive systems can improve in many ways:

- better predictions
- better representations
- better strategies
- better optimization

However, improvement alone does not imply open-ended adaptation.

A system may become extremely capable while remaining constrained by a fixed mechanism that determines how it changes.

The **Causal Transition Condition (CTC)** defines the boundary where a system transitions from:

> adapting within a fixed generative process

to:

> modifying the process that generates future adaptations

---

# Core Hypothesis

The central claim:

\[
\boxed{\Omega_t \rightarrow \Delta\mathcal{G}_{t+1}}
\]

where:

- \(\Omega_t\) = information about reachable future possibilities and constraints
- \(\Delta\mathcal{G}_{t+1}\) = change in the future space of adaptive mechanisms

In plain language:

> A system reaches a causal transition when information about reality can change the mechanisms by which future adaptation occurs.

---

# Adaptation vs Recursive Adaptation

## Standard adaptation

A system improves inside an existing possibility space.

Example:

observe reality
↓
extract constraints (Ω)
↓
modify adaptive mechanisms (Δ𝒢)
↓
create new forms of adaptation


The system does not only find better solutions.

It changes what kinds of solutions can become reachable.

---

# Formal Model

Let:

- \(X\) = system state
- \(F\) = transformation process
- \(G\) = transformation selection mechanism
- \(\mathcal{G}\) = reachable adaptive mechanism space

A basic adaptive system:

\[
X \rightarrow F \rightarrow G
\]

A recursively adaptive system:

\[
\boxed{
X \rightarrow F \rightarrow G \rightarrow \mathcal{G}
}
\]

The additional transition is:

\[
\boxed{
\Omega_t \rightarrow \Delta\mathcal{G}_{t+1}
}
\]

The system begins modifying the space of possible transformations.

---

# Relationship to Causal Permeability

CTC assumes a prior condition:

\[
\boxed{
E^* \rightsquigarrow C_{rev}
}
\]

where:

- \(E^*\) = external reality/environmental pressure
- \(C_{rev}\) = constitutional revision mechanism

This means:

> Reality retains access to the mechanism that determines future change.

Causal Permeability asks:

"Can reality reach the system's rules of change?"

CTC asks:

"When reality reaches those rules, does the adaptive mechanism space expand?"

---

# The CTC Test

A system satisfies CTC if:

\[
\Omega_t
\]

can produce:

\[
\Delta\mathcal{G}_{t+1}
\]

Operational question:

> If reality changes enough, can that change alter the mechanism by which future adaptations are generated?

---

# Predictions

CTC predicts:

## 1. Capability is not sufficient

A system can be highly intelligent while remaining trapped in a fixed adaptive topology.

---

## 2. Open-ended systems require mechanism expansion

Increasing performance is different from increasing the space of possible future improvements.

---

## 3. Reality coupling is necessary

Systems disconnected from environmental correction may optimize effectively while losing long-term adaptability.

---

# Falsification

CTC would be weakened if:

- systems without reality-driven changes to their adaptive mechanisms produce unlimited open-ended novelty
- expansion of adaptive mechanism space is unrelated to constraint information from reality
- no measurable distinction exists between fixed optimization and recursive adaptation

---

# Summary

The Causal Transition Condition is not a measure of intelligence.

It is not a measure of capability.

It is a condition describing when adaptation becomes capable of modifying itself.

The transition:

learning

↓

learning how to learn

↓

changing what learning can become


is the Causal Transition Condition.
